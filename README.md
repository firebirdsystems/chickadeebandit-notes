# Shared Notes

A [Chickadee Bandit](http://chickadeebandit.com) app.

Shared family notes — wifi passwords, house rules, recipes, anything the whole family needs.

## Features

- Simple shared notepad visible to the whole household
- Synced in real time via the hub's native notes service
- Adults can create and edit; everyone can read

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-notes/releases/latest/download/bundle.json
```
